Initial Accessibility Problems

The first Lighthouse audit identified three accessibility problems in the Student Budget Tracker website.

1. Buttons do not have an accessible name

The Save Budget button did not provide an accessible name for screen reader users.

2. Insufficient color contrast

Some text colors did not provide enough contrast against their background, making the text difficult to read.

3. Incorrect heading hierarchy

The heading elements were not in a sequential order, which affected the logical structure of the page.

Accessibility Improvements

Fix 1: Accessible Button Name

Restored meaningful visible text inside the Save Budget button so assistive technologies can identify its purpose.

Fix 2: Color Contrast

Removed the temporary low-contrast CSS and restored readable text and background colors.

Fix 3: Heading Hierarchy

Changed the summary headings from h3 to h2 to create a more logical heading structure.
