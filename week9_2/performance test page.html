YOUR FIXES

Add defer to the script, add loading="lazy" to below-fold images, and add width and height attributes.

Worst Performance Metric

The worst metric identified in the original audit was Cumulative Layout Shift (CLS).

Original CLS Value: 0.279

Lighthouse identified unsized image elements as the main cause of layout shifts. The browser did not reserve space for images before they loaded, causing page elements to move.

Additional observation: Lighthouse also identified LCP request discovery, image delivery opportunities, and unused JavaScript. The CLS value should be checked again after testing this optimized version.

Optimizations Applied

1. JavaScript Loading

Added the defer attribute to the jQuery script to avoid blocking HTML parsing.

2. Image Dimensions

Added explicit width and height attributes to all three images to help prevent unexpected layout shifts.

3. Lazy Loading

Added loading="lazy" to the second and third images because they appear further down the page.

4. Image Decoding

Added decoding="async" to allow images to be decoded without unnecessarily delaying other rendering work.

5. Image Priority

Used fetchpriority="high" for the first image because it may be visible when the page initially loads.

Conclusion

After applying performance optimizations, my Lighthouse Performance score increased from 74 to 92, an improvement of 18 points. This task helped me understand how JavaScript loading, image dimensions, and lazy loading can affect website performance and user experience.
